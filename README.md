Student Performance Analysis - Tableau Dashboard
A comprehensive Tableau dashboard project built to analyze student academic performance across various streams, courses, and marks distribution.

📊 Overview
This project visualizes student performance metrics using an Excel dataset (students marks.xlsx). It explores key insights such as stream-wise marks, distinction averages, course selections, and maximum scoring trends using an interactive Tableau dashboard.

🗂️ Dataset Structure
The underlying dataset (students marks.xlsx) includes the following columns:

Sl no: Serial number of the student

Name: Name of the student

Stream: Academic stream (e.g., Science, Commerce, Arts)

Marks: Total marks scored by the student

Bachelors: Bachelor's degree / course opted (e.g., B.Tech, B.Sc, B.Com, BCA, BBA)

📈 Dashboard Components & Worksheets
The interactive dashboard (Dashboard 1) integrates the following individual worksheets:

Stream VS Marks (Sheet 1): Compares total marks secured across different academic streams.

Average Marks of Distinction Students (Sheet 2): Highlights the performance and average scores of top-performing distinction students.

Courses Opted by Each Student (Sheet 3): Displays individual student course/degree mapping.

Marks Scored by Each Student (Sheet 4): A detailed view of individual student scores using bubble/circle charts.

Stream VS Maximum Marks (Sheet 5): Identifies the peak performance and maximum marks achieved per stream.

🛠️ Tools & Technologies Used
Tableau Desktop: For data visualization, worksheet creation, dashboard design, and interactive action filters.

Microsoft Excel: As the primary data source (students marks.xlsx).

🚀 How to Use / View
Download or clone this repository.

Open the .twb (Tableau Workbook) file using Tableau Desktop.

If prompted to update the data source connection, point it to your local path containing students marks.xlsx.
